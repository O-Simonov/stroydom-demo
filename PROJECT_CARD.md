Для будущего сайта портфолио. Все варианты — про демонстрационный проект, не про реального заказчика.

Live: https://stroydom-project.ru  
GitHub: https://github.com/O-Simonov/stroydom-demo

## Вариант 1 — короткий

**СТРОЙДОМ** — демонстрационный сайт строительной компании под ключ.

Посетитель выбирает параметры дома, оставляет заявку, менеджер получает Telegram и ведёт лид в закрытой CRM. Проект опубликован в production с HTTPS.

Next.js, TypeScript, Prisma, SQLite, Telegram, Nginx.

[Открыть демо](https://stroydom-project.ru)

## Вариант 2 — средний

**СТРОЙДОМ** — концепт коммерческого сайта для строительства загородных домов.

Задача — не только показать услуги, но и провести обращение до менеджера. Клиент смотрит проекты, подбирает параметры дома и оставляет контакты. Заявка проходит серверную проверку, сохраняется в базе, уходит уведомлением в Telegram и появляется в закрытой mini-CRM. Там менеджер ищет лиды, фильтрует по статусу и ведёт сделку: связались, отправили расчёт, переговоры, продажа или отказ.

Так выглядит рабочий цикл малого бизнеса: сайт → заявка → мессенджер → учёт обращений, без Excel и потерянных чатов. Источник визита (UTM) можно сохранить вместе с заявкой. Проект опубликован с HTTPS на обычном VPS.

Это демонстрационный проект для портфолио, не сайт действующей компании и не отчёт о продажах.

Стек: Next.js 15, TypeScript, Tailwind CSS, Zod, Prisma, SQLite, Telegram, Ubuntu, Nginx, Let's Encrypt.

Демо: https://stroydom-project.ru

## Вариант 3 — страница кейса

**СТРОЙДОМ** — демонстрационный full-stack проект сайта строительной компании.

Типичная боль малого бизнеса: лендинг есть, а заявки теряются между почтой, WhatsApp и таблицей. В этом концепте цепочка собрана в одном приложении. Посетитель видит услуги и проекты домов, выбирает площадь, этажность, материал и комплектацию, отправляет форму. Сервер проверяет данные, пишет лид в SQLite и — если бот настроен — сразу уведомляет менеджера в Telegram. Сбой мессенджера не откатывает заявку: она уже в базе.

В закрытом разделе `/leads` обращения ищутся, фильтруются и двигаются по статусам: новая → связались → расчёт отправлен → переговоры → продажа или отказ. Видны параметры дома, комментарий и UTM. Пароль, подпись сессии и секреты живут только на сервере.

Проект развёрнут на Ubuntu VPS: Nginx, HTTPS, systemd, резервные копии базы вне каталога кода, health-check, вход по SSH-ключу. Так можно показать заказчику не макет, а работающий контур.

Это портфолио-демо, а не отчёт о реальных продажах и не сайт действующей фирмы. В боевом заказе на этой базе можно добавить роли менеджеров, PostgreSQL, заметки по лиду, почтовые уведомления, аналитику или выгрузку во внешнюю CRM — каждый такой блок оценивается отдельно и в текущее демо не входит.

Стек: Next.js, React, TypeScript, Tailwind CSS, Zod, Prisma, SQLite, Telegram Bot API, Nginx, systemd, Let's Encrypt.

Смотреть: https://stroydom-project.ru · код: https://github.com/O-Simonov/stroydom-demo
