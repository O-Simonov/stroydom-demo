# PORTFOLIO SHORT — STROYDOM

## A. 300–400 символов

STROYDOM — демонстрационный корпоративный сайт строительной компании с собственной CRM. Адаптивный лендинг, форма заявок, серверная валидация, база данных и закрытый кабинет менеджера. Проект развёрнут в production; на live demo публичная форма не сохраняет персональные данные. Стек: Next.js, React, TypeScript, Prisma, SQLite.

## B. 700–1000 символов

STROYDOM — полнофункциональный демонстрационный проект для портфолио: сайт загородного строительства с лидогенерацией и mini-CRM. Реализованы презентация услуг, параметрический подбор дома, форма обращения, API, хранение заявок (в production-режиме), авторизация менеджера, статусы сделок, поиск и фильтры. Подготовлены техническая SEO-база, security headers, страницы privacy/consent и разделение demo/production для безопасной демонстрации без сохранения ПДн с публичной формы. Проект работает на собственном VPS за Nginx с HTTPS. Это не кейс реального заказчика и не отчёт о продажах — это живой пример того, как может выглядеть цифровой контур малого строительного бизнеса.

## C. Одно предложение

Демонстрационный корпоративный сайт строительной компании на Next.js с формой заявок и собственной CRM, развёрнутый в production.
