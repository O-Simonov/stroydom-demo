# CLIENT CASE — STROYDOM

## Простыми словами

STROYDOM — пример сайта для строительной компании: красивая витрина услуг и удобный способ принимать обращения клиентов.

Это **демонстрационный проект**. Он показывает, каким может быть современный сайт «под ключ» для малого бизнеса в строительстве — с формой заявки и отдельным кабинетом для менеджера.

## Какую задачу решает сайт

Посетитель знакомится с услугами, прикидывает параметры дома и оставляет контакты. Менеджер видит обращения в одном месте и ведёт их по статусам — без таблицы в Excel и хаоса в мессенджерах.

## Зачем своя CRM

Заявки не обязаны уходить только на почту. Для проекта сделана **своя закрытая CRM**: вход по паролю, список обращений, поиск, фильтр, карточка клиента и смена статуса сделки.

На текущей публичной демонстрации форма **не сохраняет** персональные данные — так безопаснее показывать проект в портфолио. В рабочей версии для реального бизнеса заявки пишутся в базу и появляются в CRM.

## Что уже можно увидеть

- понятный сайт на телефоне и компьютере;
- форму обращения;
- кабинет менеджера (после входа);
- подготовку сайта к поиску (техническая SEO-база);
- защищённый доступ к заявкам;
- аккуратный подход к персональным данным.

## Что можно добавить под конкретного заказчика

- каталог проектов и статьи;
- интеграцию с Bitrix24 / amoCRM / WhatsApp;
- аналитику и рекламные кабинеты;
- онлайн-чат;
- оплату или ипотечный сценарий;
- многопользовательский доступ менеджеров.

Стоимость и сроки — только после обсуждения задач бизнеса: **NEEDS PROJECT ESTIMATION**.
