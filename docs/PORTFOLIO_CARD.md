# PORTFOLIO CARD — STROYDOM

**Название:** STROYDOM  

**Тип:** Корпоративный сайт + CRM  

**Статус:** Демонстрационный проект  

**Описание:**  
Современный сайт строительной компании с формой обращений и собственной закрытой CRM. Проект показывает полный контур: презентация услуг, адаптивная вёрстка, серверная обработка заявок, база данных и работа менеджера со статусами. Live-версия работает в демонстрационном режиме: публичная форма не сохраняет персональные данные.

**Ключевые функции:**
- адаптивный корпоративный лендинг;
- подбор параметров дома;
- форма заявки с серверной валидацией;
- mini-CRM со статусами и поиском;
- техническая SEO-база;
- security headers и HTTPS;
- архитектура demo / production для ПДн;
- production-развёртывание на VPS.

**Стек:** Next.js 15 · React 19 · TypeScript · Tailwind · Prisma · SQLite · Zod
