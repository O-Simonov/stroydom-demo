# FREELANCE CASE — STROYDOM

## Название работы

STROYDOM — корпоративный сайт строительной компании с CRM (демонстрационный проект)

## Краткое описание

Разработан полнофункциональный демонстрационный сайт для сферы загородного строительства: презентация услуг, адаптивная вёрстка, форма заявок и закрытая CRM для менеджера. Проект опубликован как live demo. Это portfolio-кейс, а не сайт реального заказчика.

## Что сделано

- дизайн и вёрстка корпоративного лендинга (desktop + mobile);
- секции услуг / преимуществ / проектов / этапов / CTA;
- подбор параметров дома (площадь, этажи, материал, комплектация);
- форма заявки с UX-состояниями и серверной валидацией;
- backend API на Next.js;
- база заявок (Prisma + SQLite) для production-режима;
- mini-CRM: вход, список, фильтры, карточка, статусы;
- SEO-база: metadata, robots, sitemap, Open Graph;
- security headers, HTTPS на VPS;
- режим demo без сохранения персональных данных с публичной формы;
- правовые страницы (политика, согласие, cookies) как часть архитектуры.

## Технологии

Next.js 15, React 19, TypeScript, Tailwind CSS 4, Zod, Prisma, SQLite, Nginx, systemd, Linux VPS.

## Особенности

- полный контур «сайт → заявка → CRM», а не только макет;
- честное разделение demo / production;
- Telegram-уведомление в production без передачи ПДн в тексте сообщения;
- готовность к расширению (интеграции CRM, аналитика, CMS) без заявления, что это уже сделано.
