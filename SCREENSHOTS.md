# SCREENSHOTS — план изображений для портфолио

Скриншоты снимаются вручную (браузер + DevTools device toolbar).  
Отдельный screenshot-фреймворк намеренно не подключается.

## Подготовка

1. Заполнить `.env` (`CRM_PASSWORD`, `CRM_SESSION_SECRET`, Telegram).
2. Наполнить CRM демо-данными:

```bash
npm run db:clear-leads
npm run db:seed-demo
npm run build
npm start
```

3. Desktop-съёмка: окно 1440×900, масштаб 100%, светлая тема.
4. Mobile-съёмка: 430×932 (iPhone 15 Pro Max), DPR 2.
5. Файлы складывать в `screenshots/` в формате PNG.

> Перед публикацией проверить, что в кадре нет реальных телефонов, токенов и паролей.

## Обязательные изображения

### 01-hero-desktop.png
Первый экран. Видно: логотип и меню, заголовок «Строительство загородных домов под ключ», подзаголовок, кнопки «Получить расчёт» и «Посмотреть проекты», фоновое изображение. Страница прокручена в самый верх.

### 02-projects-desktop.png
Секция каталога проектов. Видно: 3–4 карточки домов с фото, площадью, этажностью и кратким описанием. Заголовок секции попадает в кадр.

### 03-calculator-desktop.png
Калькулятор параметров дома. Видны выбранные значения: площадь 150 м², 2 этажа, материал, комплектация — и кнопка «Получить расчёт». Денежная стоимость не рассчитывается, поэтому итоговой суммы в кадре быть не должно.

### 04-form-desktop.png
Форма заявки с заполненными тестовыми данными (имя «Анна Тестова», телефон-заглушка). Видно, что параметры дома подставились из калькулятора. Опционально — второй кадр с сообщением об успешной отправке.

### 05-crm-desktop.png
Главный экран CRM `/leads`. Видно: шапку «СТРОЙДОМ / Mini CRM», кнопку «Выйти», счётчики (Всего / Новые / В работе / Продажи), фильтры статусов, поиск и таблицу заявок с разными статусами. Ширина 1440 px, без горизонтального скролла.

### 06-crm-details-desktop.png
Открытая карточка заявки (drawer). Видно: имя, телефон, Telegram, комментарий, услугу, площадь, этажи, материал, комплектацию, статус, источник и UTM-метки, ссылку на страницу входа. Отдельно виден селектор смены статуса.

### 07-mobile-hero.png
Первый экран на 430 px. Видно: гамбургер-меню или мобильную шапку, заголовок, кнопки CTA. Без горизонтального скролла и обрезанного текста.

### 08-mobile-projects.png
Каталог проектов на мобильном: карточки в одну колонку, читаемые подписи, аккуратные отступы.

### 09-mobile-crm.png
CRM на 430 px: заявки отображаются карточками, а не таблицей. Видно имя, телефон, дату, статус-бейдж, параметры, источник и кнопку «Подробнее».

### 10-telegram-notification.png
Скриншот сообщения бота в Telegram о новой заявке. Видно: заголовок «Новая заявка — СТРОЙДОМ», имя, телефон, услугу, параметры дома и UTM-источник.  
**Перед публикацией скрыть:** имя бота с токеном в URL, реальные контакты, личные чаты в списке.
