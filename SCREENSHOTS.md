# SCREENSHOTS

Кадры для GitHub README и откликов. Снимать вручную (браузер + DevTools).  
Playwright/Puppeteer в проект не добавлялись.

Готовые PNG класть в `docs/screenshots/`. Пока файлов нет — в README нет картинок, чтобы не было битых ссылок.

## Подготовка

**Публичный сайт** — можно снимать с production: https://stroydom-project.ru  
Форму **не отправлять**.

**CRM** — только локально, demo-база:

```bash
npm run db:clear-leads
npm run db:seed-demo
npm run build
npm start
```

Открыть http://localhost:3000/leads  
Не снимать https://stroydom-project.ru/leads, если там живые обращения.

Перед коммитом кадра: нет паролей, токенов, `.env`, реальных телефонов, почты и имён заявителей.

## Как снять

1. Desktop: окно 1440×1000, масштаб 100%, светлая тема, без лишних расширений в кадре.
2. Mobile: DevTools device toolbar 390×844.
3. Имена файлов — как в таблице, PNG.
4. После съёмки положить файлы в `docs/screenshots/` и тогда можно вставить их в README.
