# СТРОЙДОМ — сайт строительной компании

**Тип:** full-stack commercial website / portfolio demo.

**Задача.** Показать не визитку, а полный цикл: посетитель оставляет заявку, она сохраняется, менеджер получает Telegram и ведёт обращение в CRM.

**Решение.** Один Next.js-проект: лендинг, API, SQLite, Telegram, mini-CRM, публикация на VPS с HTTPS.

**Функции**

- адаптивный лендинг и подбор параметров дома;
- форма заявки с серверной валидацией;
- Telegram-уведомление менеджеру;
- закрытая CRM: статусы, поиск, фильтры;
- UTM и страница входа;
- production: Nginx, systemd, Let's Encrypt, backup.

**Стек:** Next.js 15 · TypeScript · Tailwind CSS · Zod · Prisma · SQLite · Telegram Bot API · Nginx · systemd
