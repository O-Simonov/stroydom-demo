**Тип:** демонстрационный проект для портфолио

**Стек:** Next.js, TypeScript, Tailwind CSS, Prisma, SQLite, Zod, Telegram Bot API

**Срок:** демонстрационная разработка

---

## Кратко (2–3 предложения)

Разработал адаптивный сайт строительной компании с подбором параметров дома
и формой заявки. Заявка проходит серверную валидацию, сохраняется в базу,
менеджер сразу получает уведомление в Telegram, а обработка идёт в защищённой mini-CRM
с фильтрами, поиском и статусами сделки. Автоматически сохраняется источник обращения (UTM).

---

## Что сделал

- **Frontend:** адаптивный лендинг, каталог проектов домов, калькулятор параметров дома, форма заявки с состояниями загрузки и ошибок;
- **Backend:** API приёма заявок на Next.js, серверная валидация Zod, honeypot и rate limit против спама;
- **База данных:** схема Lead в Prisma, SQLite, миграции;
- **Интеграции:** уведомления в Telegram; сбой мессенджера не приводит к потере заявки;
- **Аналитика источников:** сквозной UTM-трекинг и сохранение landing URL;
- **CRM:** вход по паролю, подписанные сессии, список заявок, счётчики, фильтр по статусу, поиск, карточка заявки, смена статуса, адаптив (таблица / карточки);
- **Безопасность:** httpOnly-cookie, HMAC-подпись сессии, rate limit на вход, проверка Origin, серверное хранение секретов;
- **Production-подготовка:** инструкция деплоя на VPS, systemd, Nginx, HTTPS, health-check, резервное копирование базы.

---

## Ценность для заказчика

- заявки не теряются: сразу база + Telegram;
- видно, из какого канала пришёл клиент;
- менеджер ведёт сделки по статусам без Excel и переписок;
- работает с телефона;
- не требует дорогой инфраструктуры — один VPS.
